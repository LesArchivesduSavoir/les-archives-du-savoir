LES ARCHIVES DU SAVOIR · VERSION WEB

Règles de confidentialité.

Vos carnets sont personnels. Voici comment la version web utilise vos données et les choix qui vous sont proposés.

Préversion de test : n’y enregistrez pas de données confidentielles. La sécurité et la compatibilité avec les sauvegardes de la version Bureau sont encore en cours de vérification.

Qui contacter ?

Les Archives du Savoir est le nom du projet. Pour toute question concernant vos données ou pour exercer vos droits, écrivez à lesarchivesdusavoir@proton.me.

Votre compte

Pour créer un compte, vous indiquez un nom affiché, une adresse e-mail et un mot de passe. L’authentification est assurée par Firebase Authentication, un service de Google. Un lien de vérification est envoyé à votre adresse e-mail.

Ces informations servent à créer votre compte, vous connecter et vérifier votre adresse. Les données de compte sont conservées dans Firebase tant que le compte existe, sous réserve des règles de Google et des obligations applicables.

Vos carnets sur cet appareil

La version web enregistre une copie de travail de vos carnets dans le stockage de votre navigateur, sur votre appareil. Vos textes, images, couvertures et marque-pages peuvent y être conservés.

Cette copie n’est pas chiffrée par l’application. Une personne ou un programme ayant accès au même profil de navigateur peut potentiellement la lire. L’effacement des données du navigateur peut la supprimer : assurez-vous de disposer d’une sauvegarde avant de le faire.

Votre Google Drive

La connexion à Google Drive est facultative. Si vous l’autorisez, l’application demande l’accès drive.file pour créer et retrouver ses fichiers de sauvegarde dans le Drive que vous choisissez. Les sauvegardes contiennent votre bibliothèque, y compris le contenu de vos carnets.

La synchronisation est manuelle : les commandes Envoyer et Récupérer sont déclenchées par vous. Le jeton d’accès Drive est conservé temporairement en mémoire dans l’onglet. Vous pouvez déconnecter Drive dans l’application et retirer son autorisation depuis votre compte Google.

Le code de la version web utilise les données Drive pour fournir les fonctions de sauvegarde et de récupération demandées. Il ne les utilise pas pour la publicité. L’utilisation des données reçues des API Google est soumise à la politique relative aux données utilisateur des services API Google, notamment ses exigences d’utilisation limitée.

Conservation et suppression

La copie locale reste dans le navigateur jusqu’à sa suppression ou jusqu’à l’effacement de ce stockage par le navigateur. Les fichiers de sauvegarde restent dans votre Google Drive jusqu’à leur suppression ; leur gestion relève aussi des paramètres de votre compte Google. Vérifiez vos sauvegardes avant toute suppression.

Pour une demande d’accès, de rectification ou de suppression relative à votre compte, contactez-nous à l’adresse ci-dessus. La suppression du compte Firebase, des copies locales et des fichiers Drive peut nécessiter des démarches distinctes ; la version web ne propose pas encore de bouton qui efface automatiquement toutes ces copies.

Services utilisés

Le site est hébergé par Cloudflare. Google fournit l’authentification Firebase, la connexion Google et Google Drive. Ces prestataires peuvent traiter des données techniques nécessaires à leurs services, selon leurs propres politiques : Cloudflare et Google.

La préversion impose une limite d’environ 20 Mo par sauvegarde. Les services tiers sont soumis à leurs propres limites et conditions.

Évolution de ces règles

Cette page décrit la version web actuelle et pourra être mise à jour lorsque le service évoluera.
